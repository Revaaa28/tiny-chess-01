A compact chess engine built on negamax search with PVS, a transposition table, and quiescence search. Evaluation uses tapered piece-square tables blended by game phase, and the search runs to a fixed node budget, so every move is fully deterministic.

## Run it

```sh
MAKEFUN_ENV_URL=<env-url> python3 main.py
```
